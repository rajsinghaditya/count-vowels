🔤 Vowel Counter

Type any text and instantly see the vowel breakdown

Total Vowels: 0

📦 Use it in your project

This demo is powered by the vowel-counter-aditya NPM package.

npm install vowel-counter-aditya
const { countVowels } = require('vowel-counter-aditya');

const result = countVowels('Hello World');
console.log(result);
// { total: 3, a: 0, e: 1, i: 0, o: 2, u: 0 }

✨ Features

  • Counts total vowels & individual A, E, I, O, U
  • Case-insensitive — works with UPPER, lower, and MiXeD case
  • Ignores numbers, spaces, and special characters
  • Handles empty strings gracefully
  • Throws clear errors for invalid inputs
  • Zero dependencies — lightweight & fast

🔗 API Endpoint

Send a POST request to /api/count with a JSON body:

POST /api/count
Content-Type: application/json

{ "text": "Hello World" }

Response:

{ "total": 3, "a": 0, "e": 1, "i": 0, "o": 2, "u": 0 }
